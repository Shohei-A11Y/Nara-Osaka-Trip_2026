# 公開手順（毎回の作業の最後に行う）

リポジトリは2つあります。
- 作業用（非公開）：`shohei-a11y/Nara-Osaka-Trip_2026-dev`。すべての作業・ブランチ・履歴はこちら。
- 公開用（公開）：`shohei-a11y/Nara-Osaka-Trip_2026`。GitHub Pages で配信するためだけの置き場。**main の「中身だけ」を入れる。履歴やブランチは持ち込まない。**

## 手順
1. 作業用リポジトリで、いつもどおり作業ブランチ → main へマージコミットで取り込む。
2. 公開用リポジトリを add_repo（push 権限）で追加し、別フォルダに clone する。
3. 公開用の作業フォルダで `.git` 以外をすべて消し、作業用の main の中身を `git archive origin/main | tar -x -C <公開用フォルダ>` で入れる。
4. 公開前の点検（11 の H と同じ方法）。見つけても**中身は表示しない**。種類とファイル名だけ報告し、見つかったら push せず利用者に聞く。
   - 予約番号・チェックインQR（`assets/qr/` など）・合言葉が、暗号にしていない形で入っていないこと。
   - PDF が塗りつぶし済みの版であること。
   - `_指示文/` や作業用のブランチ名に関わるものが入っていないこと。
5. 変更があれば、1コミットにまとめて公開用の main に通常の push をする（コミット名の例「公開版 2026-10-01」）。**force push はしない。**
6. 1〜2分待って、https://shohei-a11y.github.io/Nara-Osaka-Trip_2026/ が新しい版（キャッシュ名）になったことを確かめる。
7. 作業用リポジトリのブランチを、公開用に push しない。
