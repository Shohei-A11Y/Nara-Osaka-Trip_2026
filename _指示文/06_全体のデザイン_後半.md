## 今回の対象（メモの節）
- **③ トップのイラスト**：大阪のモチーフ（たこ焼き・大阪城・通天閣の影絵）を加える。新幹線が1回だけ横切り、鹿が少し跳ねる。
  - 端末の「視差効果を減らす」がオンのときは動かさない。
  - 動いている間も、ほかの部分を押せること。
- **④ 表紙の下の新幹線の帯**：黒い帯を和紙色のカードにする。
  - 目立たせるのは、大きな明朝体の数字と朱色のアクセント。
  - 前半で「きょう」を作ったので、同じ情報が重なるなら整理してよい。
- **⑤ 3D乗換図**：`claude/transfer-3d-proto` の `proto/hakata-transfer-3d.html` を、のりものタブの「駅の乗り換え（3D）」として組み込む。
  - 列車のカードや日程から、場面を指定してリンクする。
  - three.js は npm から取得して自前で配信し、そのページを開いたときだけ読み込む。`sw.js` にも登録する。
  - 図の中身は完成版として扱う。直すのは、エレベーター欄の「余裕 −4分」を「チェックイン開始の3分後に着く」に改めるところだけ。
  - 図は目安であることを、ページの中に一言書く。
- **⑨ 座席表の進行方向**：「進行方向」の矢印を付け、窓側を「北側（山側）／南側（海側）」と表示する。
  - 往路・復路・かもめ（リレー）のそれぞれで正しい向きにする。
  - 城や窓の案内の内容と食い違わないこと。
- **⑪ の前半 アイコン**：上の `icon-deer.svg` に差し替える。
  - `assets/icon.svg`、`assets/icon-192.png`、`assets/icon-512.png`（PNG は Playwright で書き出す）。
  - `manifest.webmanifest` は `purpose: "any maskable"` にする。
  - ホーム画面の案内の中に出すアイコンも、同じものにする。
- **⑭ 列車の印**：いまどのへん？の現在地の印を、真上から見たかわいい新幹線の先頭車両にする。鼻先が進行方向を向くようにする。
- **⑧ 予約番号とQRに合言葉の鍵**：Web Crypto で暗号化する（PBKDF2＋AES-GCM）。
  - 合言葉を1回入れれば、その端末では以後も表示される。
  - 「画像として保存」「この端末の合言葉を消す」を付ける。
  - **合言葉は利用者から直接受け取る。** まだ受け取っていなければ、ほかの作業を進め、この項目に入る前に利用者に尋ねる。
  - 合言葉と、暗号にしていない値は、コミット・報告・新しいファイルのどこにも書かない。暗号化は一時的なスクリプトで行い、そのスクリプトもコミットしない。
  - 過去の版に残っている値は消さない（利用者の決定）。
